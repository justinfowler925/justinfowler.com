# Cowork skills: Shine, Unfog and Strike Package

These standalone ZIPs contain instructions and supporting references for Claude. They do not install private infrastructure or grant account access. Original methods and provenance are retained with each edition.

1. Download the ZIP for your task: [Shine](https://justinfowler.com/assets/cowork-skills/shine-cowork.zip), [Unfog](https://justinfowler.com/assets/cowork-skills/unfog-cowork.zip), or [Strike Package](https://justinfowler.com/assets/cowork-skills/strike-package-cowork.zip).
2. In your intended Claude workspace, open Customize → Skills → Add skill → Upload skill. Select the ZIP and save. Check it is enabled. Workspace policy may require an owner to permit skills.
3. Start a Cowork task with the files and objective needed for the job. Ask to use the named skill.

## First tasks

- Shine: “Use Shine to review the attached page. Explain the three most important usability problems and revise it. Preserve existing components and state what you verified.” Cowork supplies design guidance and bundled blueprints; executable verification requires the full Shine repository.
- Unfog: “Use Unfog to turn this request into concrete work and carry it through: [request]. Define the outcome, evidence, scope, checks and delivery.” Fowler Brain and Brutus are optional integrations, not prerequisites.
- Strike Package: “Use Strike Package to prepare for a meeting with [name, role, organization] about [objective]. Use the supplied profile link and official sources. Separate facts from hypotheses and draft three useful questions.” A profile link does not grant authenticated LinkedIn access.

Check that Claude reads the relevant skill references, uses only tools it actually has, and produces the requested result. Missing sources should stay explicit. Review before sharing outputs or sending any communication.

Clearspeed employees: use the shared copies and training linked from Nucleus. SLED Agent is company material and is available through Nucleus, not this public bundle. Usage Guard uses Claude Code hooks and is not included as a Cowork skill.

These are Cowork adaptations of the named upstream methods. Canonical adapter source and build receipts are maintained with the Nucleus company-tools release; this public mirror contains the same general-purpose files and ZIP bytes. Full runtime editions remain in their upstream repositories.
