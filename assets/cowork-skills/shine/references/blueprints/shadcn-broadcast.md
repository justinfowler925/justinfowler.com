# Broadcast and embedded video

Authored MIT-licensed reference composed from native HTML media controls and shadcn-compatible semantic chrome; not an upstream shadcn block. No provider-specific face, voice or private product code is included.

Region order: publication navigation, broadcast context, aspect-ratio media frame, caption, playback controls, viewing notes, written reporting. Media establishes its own row height. Side context is bounded on desktop and flows naturally on mobile. Long prose follows the controls. Preserve the complete camera canvas using contain; do not enlarge or crop the presenter to conceal layout whitespace.

Interaction: play the local preview, observe received media dimensions, stop and release its tracks, read the transcript. The preview is synthetic media-element proof, not provider acceptance. Verify caption-to-controls gap, aspect ratio, overflow and long text at mobile and desktop widths. Missing images and enlarged text must leave controls usable.
