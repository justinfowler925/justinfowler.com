# LinkedIn — the daily executive work surface

Draft copy for the post the four cards in this folder accompany. Not published from
this repo; paste into LinkedIn and attach `linkedin-1..4-*.png` in order.

---

Most "AI for executives" ends up as a chat box sitting next to the work. I've been
building the opposite: a daily surface where the work is already done when you open it.

Two are running now — one shaped for a CEO, one for a CRO. Same spine, different job.

The CEO opens an email before 7. Today, prep for his next three meetings, who's
waiting on him, what moved in revenue. The CRO has five analyst roles feeding three
standing outputs. Neither of them writes a prompt. That was the requirement: an
executive should be a consumer of the system, not a builder of it.

The interesting part isn't the model. It's the four rules underneath it.

The agent gathers, the code judges. Ranking is deterministic. A model that decides
what matters today decides differently tomorrow.

Every claim carries its source verbatim. A quote must be an exact substring of the
thing it came from, or the item is dropped — and the drop is logged. No paraphrase
wearing a fact's clothes.

A broken source is a visible gap. A quiet morning and a failed integration must never
look the same on the page.

Writes are proposals. It drafts, it never sends. Approving calls a stored action with
stored arguments — no model between the click and the effect.

The newest layer is voice. I call it Brutus. You never navigate; you talk, and the
screen follows.

Where it goes: one work surface per executive, shaped to how that person actually
runs a day, instead of one assistant everybody has to learn.

If you're an exec or operator thinking about this for your own week, I'd genuinely
like to hear what yours would need to do. Comments or DMs.
