03The rules underneath

The model is not the interesting part.

  1. 01
    The agent gathers. The code judges.
    Ranking is deterministic. A model that decides what matters today decides differently tomorrow.
  2. 02
    Every claim carries its source, verbatim.
    A quote must be an exact substring of what it came from — or the item is dropped, and the drop is logged.
  3. 03
    A broken source is a visible gap.
    A quiet morning and a failed integration must never look the same on the page.
  4. 04
    Writes are proposals.
    It drafts, it never sends. Approving runs a stored action with stored arguments — no model between the click and the effect.
